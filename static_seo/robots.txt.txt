# The AI crawlers again, by name, with the same exclusions repeated.
#
# Repeating them is not redundant — it is required. A crawler obeys ONLY the
# most specific group that matches its own name, and ignores the `*` group
# entirely once a named group exists. A named group containing nothing but
# `Allow: /` would therefore hand these crawlers /admin and /api/, which the
# `*` group carefully withholds. Listing the agents as a stack of User-agent
# lines above one shared rule block is the spec-correct way to say "these
# eleven, same rules" without writing the block eleven times.
#
# These groups exist to make the posture auditable: silence and permission
# look identical in a robots.txt, and this site's intent is permission.
