How it works

Cheap analysis first, thorough analysis last — cost scales with the narrow end.
01

Trend gate

Keep only names in a clean uptrend: above the 20/50/200 MAs, near 52-week highs, top relative strength. Zero API calls.

02

Multi-factor

Sector-neutral momentum, quality, estimate revisions, earnings drift and value — winsorized and z-scored.

03

Catalysts

Insider cluster buys, SEC filings, news tone & big events, options positioning, and the macro regime overlay.

04

LLM deep dive

A model scores each finalist on six dimensions and writes a thesis with a concrete invalidation level.
